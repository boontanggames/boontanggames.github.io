# Boontang Games official logo files

The owner supplied transparent full-logo and dragon-head PNG files plus vector SVG originals.

- `boontang-logo.webp` is a 1000px transparent web-optimised derivative of the supplied full logo.
- `boontang-head.webp` is a 450px transparent web-optimised derivative of the supplied dragon-head-only artwork.

The original high-resolution masters remain in the separately supplied logo pack. These site assets are not covered by the font licence.
